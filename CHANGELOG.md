# Changelog

## PC 1.8.2
- Added the VRC WinForce application icon.
- Window/taskbar icon uses the new branding.
- Desktop shortcut uses the bundled ICO file.
- One-file installer embeds and extracts PNG/ICO assets.

## PC 1.8.1
- Added global fan Pause/Resume.
- Pause forces output to 0% while data sources continue running.
- Resume starts again from 0% with normal rise smoothing.

## PC 1.8.0
- Added per-source fade-out curves and durations.
- Added heart-rate integration architecture.

## ESP32 1.3.3
- Fixed browser firmware file selection being cleared by automatic refresh.
- Retained three PWM channels, three tachometer channels and OTA.

## ESP32 1.3.2
- Enabled independent PWM outputs on GPIO4/16/17.
- Added display-only tachometer inputs on GPIO25/26/27.

## ESP32 1.3.1
- Fixed ambiguity between FAN and FAN1/FAN2/FAN3 parsing.

## ESP32 1.3.0
- Added browser-based firmware updates.
