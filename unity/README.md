# Unity Package

Current Unity package: **VRC WinForce PhysBone Sensor v0.1.0**

Files in this folder:

- `VRC_WinForce_PhysBoneSensor_v0_1_0.unitypackage` – import this into Unity.
- `VRC_WinForce_PhysBoneSensor_Source_v0_1_0.zip` – source archive for development/reference.

The package creates/rebuilds the prefab at:

`Assets/VRC WinForce/PhysBone Sensor/Prefabs/VRC_WinForce_PhysBoneSensor.prefab`

Expected PhysBone parameter base: `WinForceSensor`

Expected OSC parameter: `/avatar/parameters/WinForceSensor_Angle`

Requirements:

- VRChat Avatars SDK
- Modular Avatar

After import, if the prefab is not configured automatically, use:

`Tools > VRC WinForce > Rebuild PhysBone Sensor Prefab`
